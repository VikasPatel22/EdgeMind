EdgeMind Image Generation API

Streamlined local REST API requiring only an API key and prompt. Generates visuals directly using your current EdgeMind settings.

API Key: "edgemind" Prompt Only Direct Image Response Uses Current EdgeMind Settings
Open Studio UI

Endpoint Specification

POST GET /api/v1/generate (Alias: /api/image-gen)

This endpoint is designed for maximum simplicity. You only need to supply the pre-configured API key edgemind and your visual prompt. All generation parameters—including the active model, inference steps, guidance scale (CFG), sampler, resolution, style preset, auto-enhancement, and negative prompt—are automatically inherited from your current EdgeMind settings. Upon completion, the endpoint directly returns the synthesized PNG image!

Authentication

Supply the API key edgemind via:

  • Header: X-API-Key: edgemind (Recommended)
  • Header: Authorization: Bearer edgemind
  • Query parameter: ?api_key=edgemind
  • JSON Body: {"api_key": "edgemind"}

Request Parameters

Parameter Type Requirement Description & Behavior
api_key string REQUIRED Must match "edgemind" (via header, query, or body).
prompt string REQUIRED Description of the visual image you want to create.
format string OPTIONAL Defaults to direct image stream (PNG binary). Pass "json" only if URL/Base64 metadata is required.
⚡ Automatic EdgeMind Settings Inheritance:
When you call this endpoint, EdgeMind applies all settings currently active in the Studio and Settings panels: active model, inference steps (e.g. 1-step Hyper-SD or 25-step quality), guidance scale, sampler, aspect ratio dimensions, negative prompt, and quality enhancer.

Code Integration Examples

Direct Image Generation (Saves PNG directly) 
curl -X POST http://127.0.0.1:7265/api/v1/generate \
  -H "X-API-Key: edgemind" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A cybernetic wolf in a neon rainforest, 8k resolution"}' \
  --output image.png
Via Browser GET URL (Direct Image View) 
http://127.0.0.1:7265/api/v1/generate?api_key=edgemind&prompt=cyberpunk+city
Python (requests) — Direct Image Output 
import requests

URL = "http://127.0.0.1:7265/api/v1/generate"
HEADERS = {"X-API-Key": "edgemind"}
DATA = {"prompt": "A futuristic floating island with waterfalls, ultra detailed"}

# Endpoint generates image with current EdgeMind settings and directly returns PNG
response = requests.post(URL, headers=HEADERS, json=DATA)

if response.status_code == 200:
    with open("generated_output.png", "wb") as f:
        f.write(response.content)
    print(f"Image saved! Steps done: {response.headers.get('X-Steps-Done')} ({response.headers.get('X-Elapsed-Time')})")
else:
    print("Error:", response.json())
JavaScript (Fetch API) — Direct Image Blob 
async function generateImage(prompt) {
  const response = await fetch("http://127.0.0.1:7265/api/v1/generate", {
    method: "POST",
    headers: {
      "X-API-Key": "edgemind",
      "Content-Type": "application/json"
    },
    body: JSON.stringify({ prompt: prompt })
  });

  if (!response.ok) throw new Error(await response.text());

  // Directly returns the generated PNG image binary
  const imageBlob = await response.blob();
  const imageUrl = URL.createObjectURL(imageBlob);

  const img = document.createElement("img");
  img.src = imageUrl;
  document.body.appendChild(img);
}

generateImage("A mystical cosmic nebula shaped like an owl, 8k");

Response HTTP Headers

Custom diagnostic headers are always returned on both JSON and raw image stream responses:

  • X-Steps-Done: Contains the integer count of sampling steps performed (e.g. 1 or 20).
  • X-Elapsed-Time: Total time taken for model loading and sampling in seconds.
  • X-Image-URL: Absolute URL to access the saved PNG image.
